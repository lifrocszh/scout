# Issue tracker

Issues and specs for this repo live as Markdown files in `.scratch/`.

- One feature per directory: `.scratch/<feature-slug>/`
- The spec is `.scratch/<feature-slug>/spec.md`.
- Implementation issues live under `.scratch/<feature-slug>/issues/`.
- Research and prototype notes stay with their feature directory.

Use the issue files as local working notes. They are intentionally ignored by Git because they can contain generated run data and temporary project state.

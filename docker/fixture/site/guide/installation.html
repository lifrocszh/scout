Installing Lumen Queue

Container image

The simplest way to run a broker is the container image. Mount a volume for the log directory so topics survive restarts, and publish port 7070 for clients.

Service manager

On a server, install the lumenctl binary and run the broker under systemd. The unit file restarts the broker on failure and limits open file descriptors.

Getting started with Lumen Queue

Overview

Lumen Queue stores messages in topics and delivers them to consumers in order. You can run a broker on a laptop in under a minute, publish a message, and read it back.

First steps

Install the lumenctl binary, start a broker with default settings, create a topic, and publish a test message. The first topic tutorial walks through each command in detail.

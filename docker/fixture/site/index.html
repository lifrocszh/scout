Lumen Queue documentation

Welcome

Lumen Queue is a small, fictional message queue used as the test corpus for Scout's container stack. This site is served by the fixture container and is crawled by the coordinator and its workers.

Where to start

New readers should begin with the getting started guide, then follow the tutorials. The reference section lists the HTTP API, the command line tool and every error code.

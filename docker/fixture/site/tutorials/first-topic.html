Tutorial: your first topic

Create the topic

Start a broker, then create a topic called orders with three partitions. Lumen Queue prints the partition layout so you can confirm the topic exists.

Publish and read

Publish a JSON message to the orders topic and read it back with a consumer. The message arrives with its partition and offset, proving the round trip works.

INSERT ON CONFLICT

Upsert

INSERT ... ON CONFLICT inserts a row, or does something else if it would violate a unique constraint. ON CONFLICT DO NOTHING skips the row, and ON CONFLICT DO UPDATE changes the existing row, which is how an upsert is written.

Example

INSERT INTO counters (name, hits) VALUES ('home', 1)
ON CONFLICT (name) DO UPDATE SET hits = counters.hits + 1;

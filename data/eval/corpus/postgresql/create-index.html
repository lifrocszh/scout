CREATE INDEX

Overview

CREATE INDEX builds an index on one or more columns of a table. The default index type is B-tree, which supports equality and range comparisons and can return rows in sorted order.

Options

A multicolumn index serves queries that filter on its leading columns. A partial index covers only rows that match a WHERE condition, which keeps it small. Adding CONCURRENTLY builds the index without blocking writes, at the cost of a slower build.

Example

CREATE INDEX CONCURRENTLY orders_customer_idx
    ON orders (customer_id, created_at);

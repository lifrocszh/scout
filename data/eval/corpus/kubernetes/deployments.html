Deployments

Overview

A Deployment declares the desired state for a set of identical Pods managed through a ReplicaSet. You set the number of replicas and the container image, and the controller changes the cluster to match.

Rolling updates

Changing the Pod template triggers a rolling update that starts new Pods and stops old ones gradually, controlled by maxSurge and maxUnavailable, so the application keeps serving traffic.

Example

apiVersion: apps/v1
kind: Deployment
spec:
  replicas: 3
  strategy:
    type: RollingUpdate

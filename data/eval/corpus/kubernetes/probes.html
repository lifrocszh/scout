Liveness and readiness probes

Liveness

A liveness probe tells the kubelet whether a container is still healthy. When it keeps failing the kubelet kills the container and restarts it, which recovers an application that is deadlocked.

Readiness

A readiness probe decides whether a Pod should receive traffic. While it fails the Pod is removed from Service endpoints but is not restarted, which suits an application that is warming up or temporarily overloaded.

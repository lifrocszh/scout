Trait objects with Box<dyn Trait>

Dynamic dispatch

A trait object such as Box<dyn Shape> lets one collection hold values of different concrete types that implement the same trait. Method calls are resolved at runtime through a vtable, which costs an indirect call but avoids generating a copy of the code for every type.

Object safety

Only object-safe traits can be made into trait objects. A trait with generic methods or methods that return Self cannot be used as dyn Trait.

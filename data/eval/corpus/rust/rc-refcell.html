Rc and RefCell

Shared ownership

Rc is a reference-counted pointer that allows several owners of the same value inside a single thread. The value is freed when the last Rc is dropped. Rc itself gives only shared, read-only access.

Interior mutability

RefCell moves the borrowing rules from compile time to runtime. Combining them as Rc<RefCell<T>> lets several owners mutate one value, and a violation such as two active mutable borrows panics instead of failing to compile.

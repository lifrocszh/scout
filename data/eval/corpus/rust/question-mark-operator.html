The question mark operator

Propagating errors

The question mark operator placed after an expression of type Result returns early from the enclosing function when the value is an Err, and otherwise unwraps the Ok value. It removes the boilerplate of writing a match for every fallible call.

Error conversion

When the error is returned, the operator calls From::from to convert it into the error type of the function, so a function returning Box<dyn Error> or a custom enum can use it with several different error types. It also works on Option inside functions that return Option.

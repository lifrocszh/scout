HashMap::entry

Overview

The entry method gives access to a single slot in a HashMap, whether or not the key is already present. The returned Entry enum is either Occupied or Vacant, which lets you insert or update with one lookup instead of two.

Common patterns

The or_insert method stores a default value when the key is missing and returns a mutable reference to the value. The or_insert_with method computes the default lazily with a closure, and and_modify updates an existing value before an optional fallback insert.

Example

let mut counts = HashMap::new();
for word in text.split_whitespace() {
    *counts.entry(word).or_insert(0) += 1;
}

String and str

Owned and borrowed text

String is an owned, growable UTF-8 buffer on the heap. The str type, usually seen as &str, is a borrowed view into UTF-8 bytes that may live in a String, in a literal, or elsewhere. Functions that only read text should accept &str.

Slicing

String indices are byte offsets, and slicing must land on a character boundary or the program panics. Use chars or char_indices to walk Unicode scalar values safely.

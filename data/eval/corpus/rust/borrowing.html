References and borrowing

Shared and mutable references

A reference lets code use a value without taking ownership of it. At any moment you can have either many shared references or exactly one mutable reference to a value, never both. The compiler checks this rule at compile time.

Why the rule exists

Forbidding a mutable reference to coexist with other references prevents data races and iterator invalidation, such as pushing to a vector while a loop is reading from it.

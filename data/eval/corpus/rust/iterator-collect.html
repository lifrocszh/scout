Iterator::collect

Overview

The collect method consumes an iterator and builds a collection from its items. The target type decides what is built, so it is usually named with a type annotation or the turbofish, as in collect::<Vec<_>>().

Collecting results

Collecting an iterator of Result values into Result<Vec<T>, E> stops at the first Err and returns it, which is a concise way to parse many inputs and fail fast. The same works for Option.

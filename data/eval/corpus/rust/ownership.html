Understanding ownership

The rules

Every value in Rust has exactly one owner at a time. When the owner goes out of scope the value is dropped and its memory is released. Assigning a heap value to another variable moves it, and the previous variable can no longer be used.

Moves and clones

Types such as String and Vec move on assignment. To keep using both bindings you must call clone for an explicit deep copy. Simple scalar types that implement Copy are duplicated instead of moved.

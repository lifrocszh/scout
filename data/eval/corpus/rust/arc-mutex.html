Arc and Mutex

Sharing state across threads

Arc is an atomically reference-counted pointer that is safe to clone and send between threads. Wrapping the data in Mutex as Arc<Mutex<T>> allows several threads to mutate it, because the lock method blocks until the calling thread has exclusive access.

Poisoning

If a thread panics while holding the guard, the mutex becomes poisoned and later lock calls return an error. Releasing the guard early by dropping it keeps the critical section short.

Example

let total = Arc::new(Mutex::new(0));
let handle = { let total = Arc::clone(&total); thread::spawn(move || *total.lock().unwrap() += 1) };

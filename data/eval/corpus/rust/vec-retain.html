Vec::retain

Overview

The retain method on Vec keeps only the elements for which a predicate returns true and removes all others, in place and without allocating a new vector. The relative order of the kept elements is preserved.

Example

let mut scores = vec![3, 8, 1, 9, 4];
scores.retain(|score| *score >= 4);
assert_eq!(scores, [8, 9, 4]);

Variants

The retain_mut method passes a mutable reference to the closure, so elements can be modified while the decision to keep them is made. Each element is visited exactly once, in order.

dict.get and dict.setdefault

Reading with a default

The get method returns the value for a key, or a default when the key is absent, without raising KeyError. Calling get with one argument returns None for a missing key.

setdefault

The setdefault method returns the existing value for a key, and when the key is missing it inserts the default and returns that. It is handy for building a dict of lists, though defaultdict is often tidier.

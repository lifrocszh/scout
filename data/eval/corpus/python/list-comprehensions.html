List comprehensions

Overview

A list comprehension builds a new list from any iterable in a single expression. It can include an optional if clause to filter items and more than one for clause to combine iterables.

Example

squares = [n * n for n in range(10) if n % 2 == 0]
pairs = [(x, y) for x in range(3) for y in range(3) if x != y]

Compared with map and filter

A comprehension is usually clearer than chaining map and filter with lambda functions. Replace the square brackets with parentheses to get a lazy generator expression instead of a list.

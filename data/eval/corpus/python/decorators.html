Decorators

Overview

A decorator is a callable that takes a function and returns a replacement, applied with the at sign above a definition. They are used to add logging, timing, caching or access checks without editing the function body.

Preserving metadata

A wrapper hides the name and docstring of the original function. Apply functools.wraps to the wrapper so those attributes are copied over.

Example

def timed(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        return func(*args, **kwargs)
    return wrapper

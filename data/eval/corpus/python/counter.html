collections.Counter

Overview

A Counter is a dict subclass for counting hashable objects. Pass an iterable to the constructor and each distinct element becomes a key whose value is its number of occurrences.

Useful methods

The most_common method returns the n highest counts as a list of pairs. Counters support addition and subtraction, and update adds counts from another iterable instead of replacing them.

Example

freq = Counter(words)
top_three = freq.most_common(3)

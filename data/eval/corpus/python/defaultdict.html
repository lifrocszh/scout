collections.defaultdict

Overview

A defaultdict is a dict subclass that calls a factory function to supply a value for a missing key. defaultdict(list) groups items into lists and defaultdict(int) starts every count at zero, so no key check is required.

Example

groups = defaultdict(list)
for name, team in members:
    groups[team].append(name)

Caveat

Merely reading a missing key inserts it into the mapping. Use the in operator or get when you must not create entries.
